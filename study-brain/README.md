# Study Brain

Reference material for NCP-AAI exam prep.
All files must be markdown — convert PDFs before adding.

## How to Add a New Reference
1. Convert PDF to markdown if needed:
   ```bash
   npx pdf-to-markdown file.pdf > study-brain/filename.md
   ```
2. Add the file here
3. Claude Code will use context-mode to read relevant chunks during sessions
